Adding New Models

To obtain the models for OpenAI, please go to their website here: https://developers.openai.com/api/docs/models (click 'more' to see them all).

For Anthropic, go here: https://platform.claude.com/docs/en/models/overview (see the Claude API ID for the model name).

For Google, scroll down until you see the table with the column 'endpoint', here: https://ai.google.dev/gemini-api/docs/models.

To add a model to the app or website, copy the 'Model ID' and paste it into the Model ID field. You can then call the model any name you prefer in the Display Name field.
